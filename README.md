# 水电站机组运行检修管理平台

面向电站台账、机组运行、调速励磁、主变与闸门、大坝渗流位移监测、机组检修与发电计划的一体化水电站运行检修管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个薄封装页面
│   ├── src/components/       通用列表页 / 详情页（全模块共用一份实现）
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、排序、分页、动作流转、登记、另存、权限
│   ├── src/data/             模块元数据 / 示例数据 / 存量规整 / localStorage 持久化
│   ├── src/stores/           会话（岗位）与列表状态（收窄、排先后、页码）
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，只是薄封装；列表、详情、登记、
  另存统一由 `frontend/src/components/` 下的通用页面渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作、流转目标与归属岗位集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydropower-plant-om:entries` 这一项，或调用 `resetModule(模块)`。
- 数据层冒烟：`cd frontend && npm run smoke`（直接打 `local-service` 与规整规则，不依赖浏览器）。

## 列表条件与另存

- 每个模块的收窄条件、排先后、页码只存一份（`src/stores/list-state.ts`）：点查询、往后翻页、
  从详情页返回、另存清单，读的都是同一条，不会在翻页或返回时被默认值重建。
- 页脚总条数、状态图例、指标卡与另存清单全部按当前条件计算，另存条数与页脚总数一致；
  收窄后页码越界时自动收回到最后一页并同步回共享状态。
- 默认排序：按业务日期（操作时间、监测日期、上次校验日……）新的在前；没有日期字段的模块按业务编号排。
- 检索到的记录点行即进详情页，详情页「返回列表」停在原来的页码与条件上。

## 登记与存量数据

- **覆盖还是追加：选覆盖。** 同一业务编号（闸门编号、装置编号……）只留一条：重复登记按最新提交
  覆盖原记录（留空字段沿用原值，不拿空值覆盖），不会出现两条；新编号才追加。存量数据读取时
  也按同一口径去重——业务日期最新者为准，缺失字段用旧记录回填。
- 历史闸门记录按操作时间回填；早期没有闸门类型的按启闭机型号推定归类：含「人字」→ 人字闸门，
  含「弧」/QH 开头/含「液压」→ 弧形闸门，含「螺杆/卷扬」/QL/QP 开头 → 平面闸门，
  型号也缺失时默认平面闸门。推定结果带「（推定）」后缀，与人工登记区分开。
- 缺失的取值单独标注为「缺测」，不编造；新登记没填业务日期时按登记当天回填。
- **实测值优先**：实测（当前开度、渗流量、累计位移）与台账结论（状态、警戒/允许限值）冲突时，
  一律按实测那一套统一取值（如已关闭但实测开度大于 0 的闸门按运行中计）。
- 「X状态」字段始终与当前状态保持一致，台账与另存明细同步更新。

## 岗位权限

- 岗位在页面右上角切换；「值班管理员」是统揽只读岗，其余岗位各自归属一批模块
  （水工运行岗管闸门/渗流/位移/拦污栅/水情/泄洪，电气检修岗管励磁/主变/继电保护，以此类推）。
- 只有归属岗位能改动模块（登记、编辑、状态流转）；归属之外的岗位越权改动在
  `local-service.ts` 统一拒绝，界面上其余人只能查看不能改。
